# Skpt.js — блокировщик рекламы для ТВ-клиента Lampa

Один JS-**плагин Lampa** для телевизора (webOS / Tizen / Android TV): подключается через
**Настройки → Расширения → Добавить плагин**, без `manifest.json` и без участия браузера.
Проверено по исходникам [yumata/lampa-source](https://github.com/yumata/lampa-source/)
(commit `3c658ff`, `app_version 3.4.4`).

ТВ-специфика учтена в коде: только ES5 (старые Chromium webOS), управление с пульта,
настройки и диагностика **в интерфейсе Lampa**, потому что консоли/DevTools на телевизоре нет.

## Что изменено в v2.1.0

Акцент: **не «притворяться премиумом», а убрать рекламу на уровне данных и сети** — платные функции приложения не затрагиваются.

1. **Санитизация playdata** — `Lampa.Player.listener.follow('create', …)` (`player.js:673`) удаляет `vast_url` / `vast_banner` из `e.data` и плейлиста; дополнительно обёрнуты публичные `play()`/`iptv()`. Это важно именно на ТВ: внешние плееры webOS/Android и IPTV дергают `Preroll.show()` напрямую.
2. **Фильтр загрузки SDK** — обёртка `Lampa.Utils.putScriptAsync` не даёт подгрузиться `ima3.js` и `vender/vast/vast.js`, сохраняя семантику `complete/error` (иначе Promise `IMA.loadSDK*` зависает).
3. **Подделка конфига** — `/api/ad/get/*` на **любом** зеркале возвращает `{"ad":[]}`; `VastManager` принимает пустой массив и не перебирает зеркала по таймауту.
4. **Сетевые хуки без Proxy** — патчится `XMLHttpRequest.prototype`, совместимо со старыми ТВ-движками и jQuery 3.2.1. Подделка полная: все свойства, все `responseType`, события `readystatechange → load → loadend`, корректный `abort()`, сброс фейковых свойств при повторном `open()`. `fetch` прикрыт отдельно с фолбэком на Response-подобный объект.
5. **Хуки ставятся немедленно**, не дожидаясь `app:ready`; ожидание нужно только для `window.Lampa`.
6. **DOM-страховка** — CSS `!important` + `MutationObserver` (включая уже существующие и вложенные узлы), пауза `<video>` внутри оверлея, возврат **сохранённого** контроллера вместо хардкода `'content'`.
7. **Экран «Без рекламы» в настройках Lampa** (`Lampa.SettingsApi`) — всё с пульта, без консоли:
   - `Блокировать рекламу` (trigger) — применяется **сразу**, без перезапуска приложения;
   - `Подробный лог` (trigger);
   - `Доп. рекламные домены` (input) — строка через запятую, ввод экранной клавиатурой Lampa;
   - `Статистика и версия` (button) — `Lampa.Noty.show()` со счётчиками на 8 секунд.
8. **Эксплуатация** — ES5 only, идемпотентная загрузка, `window.SkptAdBlock` с `version / stats / classify / addRule / setHosts / isEnabled / setEnabled / uninstall`, предупреждение, если в списке плагинов осталась старая v16.

### Установка на телевизор

1. Положите `Skpt.js` на доступный ТВ HTTP(S)-сервер (или свой GitHub/Gist) — нужен прямой URL до `.js`.
2. В Lampa: **Настройки → Расширения → Добавить плагин** → вставьте URL экранной клавиатурой.
3. **Перезапустите приложение** (в Lampa есть подсказка «Для применения плагина необходимо перезагрузить приложение»).
4. Зайдите в **Настройки → Без рекламы** и убедитесь, что `Блокировать рекламу = Да`, а по кнопке «Статистика и версия» видны ненулевые счётчики после запуска фильма.

> Если ещё подключён старый `Skpt.js` v16 — удалите его из списка плагинов, иначе два набора хуков будут перехватывать XHR одновременно.

### Ключи `localStorage`

Те же ключи пишет экран настроек; править руками нужно только для продвинутых сценариев:

| Ключ | Значение |
|------|----------|
| `skpt_enabled` | `'true'` / `'false'` — главный выключатель (по умолчанию включён) |
| `skpt_debug` | `'true'` / `'false'` — подробные логи |
| `skpt_hosts` | доп. рекламные домены через запятую (`ad.example, ads.example2`) |
| `skpt_rules` | JSON-массив RegExp или `{pattern, action}` |
| `skpt_allow_hosts` | JSON-массив хостов-исключений |
| `skpt_disabled` | устаревший kill-switch, оставлен для совместимости |

Из консоли (если ТВ всё-таки подключён к DevTools):

```js
SkptAdBlock.version                         // "2.1.0"
SkptAdBlock.stats                           // счётчики срабатываний
SkptAdBlock.classify('https://cub.best/api/ad/get/preroll')
SkptAdBlock.addRule('ad\\.newmirror\\.', 'block')
SkptAdBlock.setHosts('ad.newmirror.tv, ads.second.net')
SkptAdBlock.setEnabled(false)               // выключить без перезапуска
SkptAdBlock.uninstall()                     // снять все хуки
```

### Тесты

```bash
npm test        # node --test tests/*.test.js (зависимостей нет, нужен Node >= 18)
npm run check   # node --check Skpt.js
```

17 тестов в `vm`-песочнице с заглушками `window`/`document`/`XMLHttpRequest`/`Lampa`:
классификация URL, пользовательские правила и белый список, поддельный XHR
(включая jQuery-совместимые поля), повторное использование XHR, `abort()`, `fetch`,
очистка playdata, фильтр SDK, DOM-страж, kill-switch, экран настроек с пульта и `uninstall()`.

## Дальнейшие улучшения (не реализовано)

- **Список доменов с пульта вместо строки:** сейчас `skpt_hosts` — одно текстовое поле; удобнее экран со списком и кнопками «добавить / удалить» через `Lampa.Input` + `Lampa.Select`.
- **Кнопка «Проверить защиту»:** сделать тестовый запрос к `/api/ad/get/preroll` и показать в `Noty`, подменился ли ответ, — диагностика без консоли.
- **Уведомление о первом срабатывании:** один раз показать `Noty` «Реклама отключена» при первом заблокированном запросе, чтобы владелец ТВ с пульта видел, что плагин живой.
- **Удалённый список правил:** тянуть JSON с новыми зеркалами (кэш + подпись), чтобы не обновлять файл плагина на ТВ вручную.
- **Старые платформы `orsay`/`netcast`:** в `manager.js` для них `Preroll`/`Banner` не инициализируются — можно добавить отдельную проверку/ветку.
- **CI:** `node --test` + линтер ES5 (`eslint`, `ecmaVersion: 5`) на каждый коммит.

## Дисклеймер

Скрипт отключает показ рекламных материалов в стороннем приложении. Используйте его
только там, где это допустимо правилами сервиса и законодательством; официальная
поддержка проекта — [CUB Premium](https://cub.red/premium). Ответственность за
соответствие условиям использования Lampa и источников контента лежит на владельце ТВ.
